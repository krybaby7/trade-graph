# L2: Real-data checks (part 1, practice range, 2026-10-19)

For the owner: The first real practice-range test is done: both starting strategies lose money after fees on almost
every coin, month range and fee level (59 of 60 results), because before fees they roughly break even and the fees
then decide the result. In the falling months (April to July) they lost less than simply holding the coin; in the
rising months (August and September) they missed almost all of the rise. Before the install you decide whether the
team first works on better strategies; also, the install checklist misses a step without which the Trader could make
no day plan at all (below).

Branch: `claude/day-trader-engine-20261012` (local commit, not pushed). Local step, no pull request. Code: the
integration tree at `137deb4` (no code changed). Free public data only: the Kraken archive in the private candle file
(L1). No key, no paid call, no network call, no order; the trading system was not started. The owner was told each
command before it ran (D263).

## Finding for L3: confirmation reports must exist inside the installed system

`DayPlanService` refuses a day plan unless its strategy version has a practice-range **confirmation** report in the
same state database (`application/day_plans.py`, D138 item 5), and the Trader's `practice_range` context lists only
versions with one (`application/trader_workflow.py`). Only the `practice-range-*` commands create reports; no
department or service does. [L3-INSTALL-CHECKLIST.md](../../docs/L3-INSTALL-CHECKLIST.md) has no step that registers
strategies and runs confirmation replays in `/var/lib/trade-graph/trade_graph.sqlite`. As written, after L3 every day
plan would be refused and the scored test would make no trade. Needed: a checklist step after step 7 (the candle file
is in place) and before step 15, inside the new image: `practice-range-register`, `practice-range-study` and the
confirmation `practice-range-run` for each strategy version the Trader may use, with the strategy files available in
the image or the owner folder. Also: no department can create practice reports, so new strategy versions reach the
Trader only through these owner-run commands.
