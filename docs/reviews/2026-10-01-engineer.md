## Implemented T13 workflow

`EngineerHandler` resolves the persisted commission, owner/mandate revisions, shared monetary allocation,
active/source baseline and scheduler fencing token before dispatch. It supplies only bounded allowlisted source
data and typed task evidence to the model, with no shell tools, private database, credentials or policy mounts.

The request/run/provider/model/billing identity and attempt count commit before the gateway dispatch.
Each generation, schema repair, patch repair and known transport retry uses a distinct durable invocation and reservation.
One schema repair is allowed; all attempts fit the commissioned maximum and shared task/root budget.
Retries have a persisted 30-second due time, rather than an immediate loop. Specific independent checker failures
and the permitted previous patch inform repairs. A model refusal, exhausted allowance or final validation failure
produces an evidence-linked terminal result without changing the active version.

The runner writes a real patch and creates independent candidate-bound evidence. Scheduler fencing is checked
at candidate publication, separately from revocable authority. A valid worker can retain a failed candidate after
authority changes during checks; a replaced worker cannot publish even a candidate failure. Receipts survive both.

Recovery reuses durable model responses and published candidates without additional model attempts, receipts or
completion reports. A lost external response becomes an uncertain hold and waits for reconciliation; no provider
idempotency guarantee is invented. Cost-only recovery still records uncertainty after an owner halt/revocation.
Local-check recovery uses a fresh private directory, retains previous directories and fences the old token.
Three local recoveries per invocation bound retained staging/check work; they do not consume another paid generation.

The provider transport now maps actual HTTPX exceptions/status denials into gateway failures, retains reported usage,
leaves missing usage unresolved and sanitizes provider errors. The configured/request timeout reaches HTTPX.
That timeout bounds I/O inactivity, not a hard total process wall-clock kill. Legacy custom transports remain compatible
without retrying a possibly side-effecting call after `TypeError`.

The CLI demo now exercises persisted Leader commission -> Engineer rejected patch -> gateway-funded synthetic repair
-> real independent checks -> Secretary evidence -> gateway-backed Leader activation. Its rejected-attempt receipt
comes from the actual gateway invocation. Artifact consumer reload remains T14.
